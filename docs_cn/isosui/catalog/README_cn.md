# 图目录呈现

[English](../../../docs/isosui/catalog/README.md) · [首次使用](../usage_cn.md) · [设计](../design_cn.md)

**目标设计，尚非现有功能。** IsosUI 呈现 IsOS 目录，不注册运行时节点类型，也不拥有负载字段。首次使用按 **core → layer → group → node type** 选择。类型描述说明类型用途；可编辑的实例描述说明本次配置。类型 ID、设置、端口、能力、默认值、单位、校验和兼容规则以所有者 `interfaces/` 契约为准，不在 UI 中复制。

| 层级 | UI 行为 | 所有者及示例 |
| --- | --- | --- |
| Core | 显示就绪、包锁定与状态；不可用时保留原因。 | EOS、EGIA、IsOS 各自拥有实时状态。 |
| Layer | 过滤主要领域，不改变图。 | EOS 硬件、进程、控制；EGIA 智能体阶段；IsOS 管理。 |
| Group | 显示相关注册类型及包来源。 | EOS 相机/底盘/机械臂、MuJoCo 进程、EGIA 感知/上下文/决策。 |
| Node type | 显示目录提供的非空类型描述、位置、设置与类型化端口；仅兼容时允许添加。 | 节点与字段以各核心的接口契约为准。 |
| Node instance | 分别显示可编辑名称/描述、保存设置、错误、运行健康和来源连线。 | IsOS 拥有保存图；EOS/EGIA 拥有运行状态。 |

UI 用精确 `(core, layer, group, type_id)` 查找注册记录，不用翻译后的标签或文件夹名称推导身份。旧侧文件缺少 `NodeType.description` 时，显示服务端兼容描述并标记回退。固定包缺失或无效时，保留图中的 ID、显示原因并阻止应用。兼容的未知字段在草稿中保留；未知未来图版本只读。

节点检查器按 **身份与描述 → 包/版本和可用性 → 设置与选择器 → 端口与连线 → 校验 → 实时状态/日志链接** 排列。选择器保留稳定值，标签与描述只用于呈现。每条连线在应用前显示 nice 优先级和频率上限，包括旧图默认值。日志链接先打开当前运行最初的就绪/故障事件，再按节点路径和关联 ID 过滤。过期修订、选择器刷新和面板持久化算法见[工作台设计](../design_cn.md)。
