# IsosUI 文档

[English](../../docs/isosui/README.md)

IsosUI `0.1.0` 是 IsOS 的图编辑器和本地工作台。首次使用请按[使用指南](usage_cn.md)的操作顺序阅读，再看[设计](design_cn.md)中的工作区与算法，最后看[实现 TODO](todo_cn.md)。IsOS 拥有图和本地 API 契约，EOS 拥有控制与观察负载契约。界面呈现、编辑这些契约，不再定义第二种图格式。

**状态：** 仓库根目录 README 描述已实现的编辑器。这里明确区分现状与集成 0.x 目标；目标尚未作为 UI 功能发布。
