# 首次使用：图与工作台

## 当前路径

1. 安装 Node.js 22 和 npm 10，在本仓库运行 `npm ci` 和 `npm run build`，并在 IsOS 中选择生成的 `dist/local`。也可用 `npm run dev` 在 `127.0.0.1:16001` 启动独立前端；图编辑和实时控制仍需要 IsOS、EOS 回环 API。
2. 运行 `isos serve`，打开 `/en/isos` 或 `/cn/isos`。Home 显示管理器设置、已安装包收据、核心就绪状态、进程状态与全部来源日志。API 离线应显示阻塞原因，而非空图。
3. 在 IsOS 中安装或链接精确的 `island/mujoco-sim@0.1.1`。在 Graph 选择 `sim-hardware` 节点集，预览新增节点并选择场景。当前编辑器从 `/backends` 获取场景，从 `/node-options` 获取设备和适配器；包选项尚不是通用资源选择器。
4. 选中节点，阅读描述并配置类型声明的字段；连接兼容的输出和输入端口，然后在“高级操作”中选择 **Check graph**。若连线高亮，选中它：检查器显示来源/目标类型 ID、IDL 字段单位，以及该输入端口的 IsOS 拒绝代码、路径和原因。“诊断”区域保留完整服务器结果。修正端口或节点设置后再次检查；修改草稿会使上次检查结果过期。检查器里的部署状态与节点实时健康分开，后者可在 EOS 监视器查看。确认检查通过后，再用 Graph 主操作保存并运行修订。由服务器验证、应用图；浏览器草稿本身不能控制 EOS。
5. 等待 Home 显示就绪，再打开 EOS 控制与监视。只有活动图声明的节点才显示控制。当前 Graph 的 View 菜单可浮动整个 EOS 或 EGIA 窗口；Vision、控制、监视和日志尚不能分别浮动。
6. 若启动前失败，打开 Home Logs。固定的管理器会话锚点显示首条软件包或 Apply 故障，即使详情筛选隐藏了该来源。启动后，面板固定本次运行的首条就绪或故障事件。可按来源、级别、节点路径或关联 ID 筛选后续详情行，锚点仍可见。将运行 ID 和关联 ID 用于 EOS／EGIA 排查。实时就绪及保存／活动修订以 Home 状态为准；活动修订过期会阻止实时控制。
7. 通过 IsOS 停止部署。升级时安装精确的新包版本，预览节点、检查图、应用新修订并重启；保留旧图和包收据以便恢复。

仓库根目录 [README](../../README_cn.md) 记录已实现的开发命令、API 来源和构建输出。包安装和进程操作由 IsOS 负责。

## P07 日志导航

包或 Apply 失败后打开 Home 日志。面板向 IsOS 请求 `view=current`，在来源、级别、节点和关联筛选器上方显示管理器会话中的首条包／Apply 故障。尚未收到该事件时显示锚点待定；空列表不表示成功。IsOS 准入部署运行后，面板切换到该运行的首条就绪或故障事件，再显示后续详情行。停止、进程退出或管理器重启后仍选择该运行，直至 IsOS 准入下一次运行。实时就绪及保存／活动修订以 Home 状态为准；日志只解释其发生时的事情。

暂停 Follow 后查看行内安全的来源、核心、事件代码、运行 ID、关联 ID 和图节点指针。先看固定首事件，再筛选详情行。保留策略或轮转造成丢失时，面板显示缺口通知并在同一运行内继续；收集器不可用时保留末次行和游标，并持续显示错误直至恢复。新准入运行显示可见边界及自己的锚点。浏览器控制台诊断与 IsOS 事件分开。P07 面板显示归属方报告的事件身份；IsOS 不支持显式响应时保留旧版兼容视图。详见 [P07 UI 契约](interfaces/log-cursors_cn.md)。

筛选后空页若游标推进且无诊断，仅表示暂时没有匹配详情行，不是缺口。状态报告 `run_id_state:unavailable` 或当前日志返回 `log_scope_unavailable` 时，将旧行标为过期，身份恢复期间以实时状态为准。Run 返回 `log_scope_publish_failed` 表示没有子进程启动，但持久运行记录可能仍幸存；解释范围前须刷新状态与当前日志。这两种情况都不允许 UI 自行选择管理器会话或宣称就绪。

## 目标交互——计划中

[R07 浏览器原语客户端](interfaces/browser-results_cn.md)是本分支的设计目标。其最小 EOS 卡选择一个合格的活动 `base.velocity` 绑定，显示图解析的 base 目标及有界 `body_velocity` 字段，只在操作员点击 Invoke 后发送 `primitive_typed`。受管理的模拟适配器可在 R06 验证真实 MuJoCo 运动前证明此路径。记录 IsOS 运行 ID 和相等的保存／活动修订，取得 EOS 单调时间，浏览器本地 `sending` 期间持续显示生成的命令 ID。EOS 返回 `InProgress` 时，只有 IsOS 仍报告同一运行中的部署，才用该 ID 和修订读取有界公开 `result` 操作。精确显示 `Completed`、`Failed`、`Cancelled`、`Rejected`、`InProgress` 或 `OutcomeUnknown`；桥接离线、旧运行或修订过期都显示不可用，绝不当成成功。发送超时后不重发命令。打开无筛选的 Home 当前运行日志；只有 EOS 所有者事件提供与命令对应的有效关联 ID，才能预填关联筛选。命令 ID 单独显示。即使 EOS 离线，IsOS 部署 Stop 仍须可用。MuJoCo 运动控件必须等 R06 物理停止验证后才能开放；完整每绑定目录、节点卡及浮动面板仍属 U04/U03。

Graph 首先显示可搜索的注册类型库。选中类型时显示非空的**类型描述**、层级位置、能力、端口契约和设置帮助；选中实例时显示可编辑的实例描述。配置表单按目录元数据生成。类似模型权重选择器的控件按**节点与设置**搜索已验证的选项，先支持场景和设备。选择器标题显示精确包和版本锁定；每项显示稳定 ID、名称、描述、可用状态与原因。已保存但不可用的值保持可见并解释原因，不能静默替换；Check graph 仍可用并报告未解析或无效选项；修正前阻止 Apply。包路径留在 IsOS 内部，图只保存稳定 ID 和精确包版本。

鼠标悬停或键盘聚焦节点时，悬停时在指针旁、聚焦时在节点旁，并浮于其他节点之上显示信息卡。分别显示注册类型描述与实例描述，以及层级、端口和单位；仅在所属核心报告时显示实时健康。将卡片限制在视口内，提供触摸入口，同时不妨碍拖动节点和编辑连线。

每条连接可编辑 `priority`（nice 值 `-20..19`，默认 `0`）及可选 `frequency_hz`（有限正数，表示传输频率上限）。检查器根据 IsOS 验证结果编辑。正常缩放和键盘焦点提示都显示两个值；图例将优先级、频率与传输方式、负载类型分别解释。尚无运行时路由的边明确标为**仅设计**。优先级只影响调度，不绕过 Dispatcher 安全准入。

工作区让**控制**、**监视**、**Vision**、**日志**面板分别停靠或浮动。浮动面板有拖动、调整大小、焦点顺序、关闭/停靠操作、有界视口和本地布局保存；恢复时把几何位置限制在当前视口。窄屏按顺序叠放，保留 Stop、连接失败和修订过期提示。工作页面采用紧凑对齐的行、透明或轻微半透明背景；视觉概览页面可用更宽的间距。两类页面共享参考 Island-web 的样式 token、克制的边框、可见键盘焦点、28–30 px 桌面控件和至少 44×44 px 触摸目标。

完整 U04 原语演示按以下顺序使用：查看节点，检查并应用图，等待 EOS 就绪。在 EOS 控制面板中选择一个活动原语绑定并查看从图解析出的唯一目标；要改变目标须编辑图并 Apply。面板显示两种节点描述，并按所属契约显示类型化原语字段。通过现有回环 `primitive_typed` 桥接调用。先显示浏览器本地的发送状态，再根据关联响应显示精确的 `Completed`、`Failed`、`Cancelled`、`Rejected`、`InProgress` 或 `OutcomeUnknown`；`InProgress` 在经授权结果读取确认前保持未完成。当前运行日志与实时健康分别呈现；仅当 EOS 所有者事件提供对应的有效 ID 时按关联筛选日志。图上的连线本身不表示命令已经执行。通过 IsOS 停止。完整 U04 控制流仍在 R07 最小卡之后规划。
