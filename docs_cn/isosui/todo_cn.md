# 0.x UI 目标实现 TODO

本队列对应 [IsosUI 0.1.0 实现](https://github.com/Island-Team/IsosUI/milestone/1) 和共享的 [M4 智能体与工作台关卡](https://github.com/Island-Team/Island-eos/milestone/4)。按依赖顺序完成下列步骤；首次使用时每一步先显示实时状态，再显示本次运行的因果日志。

[English](../../docs/isosui/todo.md) · [设计](design_cn.md)

1. 更新 API 适配层以读取多版本图及 IsOS 节点/类型/选项契约。保留未知兼容字段和旧来源引用。连接、目录版本与 UI 发布版本分别管理。
2. 用目录字段元数据生成实例表单。增加可搜索包选项选择器、过期响应处理、不可用值呈现和 Apply 阻断。先覆盖场景和设备；模型权重资源只是扩展点，本次不实现 EGIA tensor 执行。
3. 增加每条边的优先级/频率编辑和显示。测试旧图默认值、无效 nice/频率、不相关边保留、键盘标签和仅设计路由。频率的主要显示依据是配置的边限值，而非端口提示。
4. 为节点增加悬停、键盘焦点和触摸入口的信息卡。区分类型与实例描述，显示端口、单位及所属核心报告的健康。测试视口限制、层叠、键盘访问以及节点拖动和连线编辑。
5. 将整体核心窗口拆为分别可停靠的控制、监视、Vision 和日志面板。在 R07 最小类型化绑定发送方／消费者之后，为每个活动原语绑定提供完整控件、显示活动图解析出的唯一目标（修改须编辑图并 Apply），并通过现有 EOS 浏览器桥接使用 `primitive_typed`。显示浏览器本地发送状态与精确关联的 `Completed`/`Failed`/`Cancelled`/`Rejected`/`InProgress`/`OutcomeUnknown` 结果；仅通过经授权结果读取跟进 `InProgress`。不得暗示图连线已执行。保存并限制布局，测试焦点、键盘操作、窄屏、订阅、过期修订、命令失败和可见 Stop。
6. 将日志与 Home 首次使用流程升级到共享 JSONL 事件/游标契约。测试轮转、当前运行边界、来源筛选与浏览器来源标识；区分原语命令结果与因果运行日志。
7. 校对中英文文案、两种主题和本地/托管构建中的工作/视觉页面样式。运行 `npm test`、`npm run build` 和无障碍检查；完整输出放在 `logs/test/<run-id>/`，发布前记录可复现命令与结果。

验收需要 IsOS → EOS → MuJoCo → EGIA 集成运行，包含已验证包、保存/活动修订一致、实时监视与控制、故障及安全停止。物理 ROS/厂商设备和 EGIA tensor 节点属于后续工作。
