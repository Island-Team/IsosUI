# IsosUI documentation

[中文](../../docs_cn/isosui/README_cn.md)

IsosUI `0.1.0` is the graph editor and local workbench for IsOS. Read [first use](usage.md) in operator order, [the core → layer → group → node catalog projection](catalog/README.md), [the design](design.md) for the workspace and algorithms, [P07 log navigation](interfaces/log-cursors.md), then [the implementation TODO](todo.md). The IsOS graph and local API contracts belong to IsOS; EOS owns control and observation payloads. This UI renders and edits those contracts without defining a second graph format.

**Status:** The README at the repository root describes the implemented editor. These pages distinguish that behavior from the integrated 0.x target. The target is a design, not a released UI feature.
