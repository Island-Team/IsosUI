# IsosUI

IsosUI 是公开的 IsOS 配置图编辑器源码，采用 Apache-2.0 许可证。编辑器在本仓库维护；IsOS 提供本地 API，Island-web 托管固定版本的前端构建产物。

## 开发与构建

使用 Node.js 22 和 npm 10 或更新版本：

```bash
npm ci
npm run dev
npm test
npm run build
```

`npm run build:local` 输出 `dist/local/`，使用同源 `/api/isos/v2`。设置 `ISOSUI_REPO_PATH` 或 `ISOS_WEB_DIST` 后，IsOS 会通过自身的环回服务提供本地构建。`npm run build:hosted` 输出 `dist/hosted/`，资源路径以 `/isosui/` 开头，直接访问本机 `http://127.0.0.1:16000/api/isos/v2`。本机 IsOS 服务必须允许准确的托管来源。编辑器通过地址和端口连接，无需 URL 令牌或 Authorization 请求头。

## 工作台

工作台包含首页、节点图、EOS 和 EGIA 页面。首页显示 IsOS 管理的后端软件包、配置检查、已保存和运行中的修订、进程状态、运行/重启/停止操作及有限长度的日志。EOS 与 EGIA 页面暂为后续运行面板预留。节点图从 IsOS `/api/isos/v2/node-graph` 读取唯一编写的图，从 `/api/isos/v2/node-types` 读取注册类型目录。节点类型确定核心、层、组、生命周期、配置字段和类型化端口。添加节点会在类型确定的位置创建实例。当前类型定义使用 `@v1.0`；图格式仍为 `2.0.0`，IsosUI 的应用版本独立维护。

选择实例后，可编辑标识、标签、描述、能力和类型化设置。后端软件包、版本、场景和设备选项可从 IsOS `/backends` 读取。硬件适配器、坐标系、观测及安全边界通过高级 JSON 编辑。可搜索类型目录，双击画布添加所选类型，将输出端口拖到类型匹配的输入端口；每个输入只允许一个来源。Ctrl+Z/Ctrl+Y 撤销或重做图编辑，Delete 删除选中节点。验证按图路径显示服务器诊断，应用会先验证再保存修订版本。编辑器有未应用的更改时，首页会禁止运行和重启。刷新前会提示放弃本地更改。画布位置只是浏览器中的偏好，不属于节点图数据。桌面控件约 30 像素高，触屏控件至少 44×44 像素。

IsOS MuJoCo 后端检查器提供“显示 MuJoCo 窗口”设置，在该后端节点的环境变量中写入 `MUJOCO_GUI=1`。应用节点图并启动或重启由 IsOS 管理的后端后，窗口显示 EOS 使用的同一个仿真实例。关闭此设置时仿真以无界面模式运行。

节点边框颜色区分进程、相机、底盘、机械臂、调度器和 EGIA 类型族；端口和连线颜色区分相机数据、观测、运动、请求、结果、健康、状态、上下文和规划。标签与端口形状重复表达这些含义。画布只显示简短配置摘要，不把实时数据负载当作节点设置。

节点图只管理配置，不承载实时相机或运动数据。IsOS 在重启受管进程时启用已保存的修订版本。编辑器不会创建第二条执行器命令路径。

两个构建目录都包含 `index.html`、`assets/`、`IslandTeam.png` 和 `manifest.json`。清单包含 UI 版本、源码提交、构建目标和 IsOS API v2 版本。IsOS 在 `/en/isos` 与 `/cn/isos` 提供本地页面；Island-web 在对应路径提供托管 HTML，并把资源放在 `/isosui/`。

手动发布工作流从现有的 `v<package version>` 标签构建两个压缩包与 `SHA256SUMS`。普通开发和固定提交构建不需要发布版本。
